# exercises/

Throwaway practice code: Go Tour snippets, TypeScript experiments, SQL scratch queries.

Nothing in here is imported by `api/` or `web/`, and nothing here needs to be tidy.
If an idea works out, rewrite it properly in the real package. Do not move it over as-is.

Tip: give each experiment its own folder with its own `go.mod`
(`go mod init scratch/whatever`) so it never interferes with the API module.
